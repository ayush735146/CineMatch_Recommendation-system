# CineMatch: AI Recommendation Engine

AI-powered personalized movie recommendation system using the MovieLens dataset.

## Features
- Collaborative Filtering
- Cosine Similarity
- SVD (Singular Value Decomposition)
- RMSE evaluation
- Top-5 movie recommendations
- Streamlit interface

## Tech Stack
Python, Streamlit, Pandas, NumPy, Scikit-Learn, Surprise, Matplotlib, Seaborn.

## Project Flow
User ID → User Profile → Rating History → SVD Prediction → Ranking → Top-5 Recommendations → Streamlit UI
